## 三、组件库选型

### 3.1 基础组件策略

**方案：Radix UI + TailwindCSS**

理由：
- Radix UI 提供 Headless 组件，完全可控样式
- 配合 TailwindCSS 实现高度定制
- 避免 shadcn/ui 的依赖束缚

### 3.2 具体组件映射

| 功能 | 组件 | 替代方案 |

| 对话气泡 | 自定义 | - |

## 五、API Mock 方案

### 5.1 使用 json-server 或 msw

**推荐：msw (Mock Service Worker)**

优点：
- 在浏览器层面拦截请求
- 支持真正的 SSE mock
- 开发体验好

### 5.3 SSE Mock 示例
```typescript
// 使用 setInterval 模拟流式输出
function mockSSE(onMessage: (data: string) => void) {
  const response = '你好，我是小智助手';
  let index = 0;
  
  const interval = setInterval(() => {
    if (index < response.length) {
      onMessage(response[index]);
      index++;
    } else {
      clearInterval(interval);
    }
  }, 50);
}
```

## 七、启动步骤

```bash
# 1. 创建项目
npm create vite@latest xiaozhi-frontend -- --template react-ts

# 2. 安装依赖
cd xiaozhi-frontend
npm install

# 3. 安装额外依赖
npm install zustand @radix-ui/react-dialog @radix-ui/react-dropdown-menu @radix-ui/react-switch @radix-ui/react-tabs @radix-ui/react-accordion @radix-ui/react-toast @radix-ui/react-tooltip @radix-ui/react-popover @radix-ui/react-select @radix-ui/react-checkbox @radix-ui/react-radio-group react-router-dom axios react-hook-form @hookform/resolvers zod i18next react-i18next lucide-react react-markdown framer-motion clsx tailwind-merge

# 4. 配置 TailwindCSS
npx tailwindcss init -p

# 5. 启动开发服务器
npm run dev
```
