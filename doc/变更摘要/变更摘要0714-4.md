# 变更摘要 2026-07-14

## 后端更新

### AI 模型配置
- 新增 `ModelConfigService` 支持从 config.yaml 预置模型
- 支持通过 API 动态添加/更新/删除模型
- 实现 `OpenAIAdapter` 和 `ClaudeAdapter`
- 模型配置接口：`/models`
