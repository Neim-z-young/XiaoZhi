# 小智 XiaoZhi - 项目初始化指南

## 一、环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Node.js | >= 20.x | LTS 版本 |
| pnpm | >= 8.x | 包管理器 |
| PostgreSQL | >= 15.x | 主数据库 |
| Redis | >= 7.x | 缓存 |
| Docker | >= 24.x | 本地开发（可选） |

---

## 二、快速初始化

### 2.1 创建项目
```bash
# 创建 NestJS 项目
pnpm dlx @nestjs/cli new xiaozhi-backend --packageManager pnpm --skip-git

cd xiaozhi-backend

# 安装核心依赖
pnpm add @nestjs/core @nestjs/common @nestjs/platform-express @nestjs/config
pnpm add @nestjs/typeorm typeorm pg
pnpm add @nestjs/jwt @nestjs/passport passport passport-jwt
pnpm add @nestjs/swagger swagger-ui-express
pnpm add ioredis
pnpm add class-validator class-transformer
pnpm add uuid

# 安装开发依赖
pnpm add -D typescript @types/node @types/express
pnpm add -D jest @nestjs/testing ts-jest
pnpm add add -D eslint prettier
```

### 2.2 目录结构

```
│   └── pipes/                 # 管道
├── modules/
│   ├── auth/                  # 认证模块
│   │   ├── auth.module.ts
│   │   ├── auth.controller.ts
│   │   ├── auth.service.ts
│   │   ├── strategies/
│   │   └── guards/
```

## 三、Docker 本地开发环境

### 3.1 docker-compose.yml
```yaml
version: '3.8'

services:
  postgres:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: xiaozhi
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

volumes:
  postgres_data:
  redis_data:
```

### 3.2 启动
```bash
docker-compose up -d
```

## 四、数据库初始化

### 4.1 运行 Schema
```bash
# 使用 TypeORM 同步（开发环境）
# 或手动执行迁移脚本

psql -h localhost -U postgres -d xiaozhi -f doc/后端数据库Schema设计.md
```

### 4.2 pgvector 启用
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

